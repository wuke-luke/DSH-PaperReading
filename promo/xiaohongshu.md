## 正文

以前读一篇英文论文的真实流程：
PDF 里查词 → 浏览器翻译整页 → 复制段落问 GPT → 笔记再记到另一个 app。
四个窗口，来回切，读到第三页就不知道自己在哪了。

最近换了个方式：在 DeepSeek Harness 里装了一个插件 **DSH-PaperReading**，四件事收进同一个侧栏。

📥 **导入**
本地 PDF、arXiv 编号、arXiv 链接，拖进去就行。

🀄 **整页对照**
左边中文页、右边原版页，逐页并排。版式跟着原文走——双栏、图表、页脚都在原位，图里的字不会被乱翻。

🔍 **划词翻译**
鼠标拖一句，光标旁边直接出译文，不用开新窗口。

💬 **伴读对话**
回答带 [p.12] 这种页码，点一下跳回原文那一页。公式能正常渲染，不会给你一堆 LaTeX 源码。

另外还有笔记、框架图、相似论文推荐、云同步（本地文件夹 / WebDAV / Google Drive / 百度网盘同步空间），每篇论文的 token 消耗也能看到。

我最喜欢的一点：**全在本机**。PDF、译文、笔记存在自己电脑上，插件不内置任何第三方密钥，模型可以用 DSH 登录的账号，也可以填自己的 API Key。

适合谁：经常读英文论文的研究生 / 算法工程师 / 需要追 arXiv 的人。

装法放图 4 了，开源 MIT，GitHub 搜 **DSH-PaperReading** 就能找到（评论区也有）。
